Windows Gets Two-Click AI Agents, Faster Start Menu, and a Slider for Memory

Microsoft and Nvidia launched RTX Spark laptops built on Arm chips, while Microsoft separately says Windows 11 is up to 20 percent more responsive after months of fixes.

The wire said: How Windows is being optimized for Nvidia’s RTX Spark laptops · The Verge

By The Daily Spin Desk · TechnologyOct 15, 2026 14:38 UTC · 3 min read

Catch up

Nvidia's RTX Spark laptops pair an Arm CPU with a Blackwell GPU and unified memory, and Microsoft has spent months tuning Windows for them. Separately, Microsoft promised earlier this year to fix Windows 11's performance and reliability.

Why it matters

If you buy a Windows laptop, the software may now run better on modest hardware, and a new class of Arm machines wants to run AI models and games locally. Some headline features, including Recall, are still missing at launch.

Microsoft and Nvidia held a launch event in San Francisco for the first RTX Spark laptops, which look like ordinary Windows machines but run on Arm chips rather than the x64 designs from Intel and AMD, according to The Verge. Translation: x64 and Arm are two different languages for telling a processor what to do, and most Windows software was written in the first one. Microsoft's solution is to translate in real time and hope nobody notices.

That translation is done by an emulator called Prism, which handles apps that lack a native Arm version. Peter Dawoud, a Microsoft principal program manager, told The Verge that "Emulation isn't generic. Each platform needs tuning." Microsoft says it ships a compatibility update every month, which is a polite way of saying the translator is still learning idioms.

The pitch is local AI. Windows on RTX Spark has a Get Started experience that lets users find and install an AI agent in two clicks. Translation: an agent is an AI program that does tasks for you, and local means it runs on your laptop rather than in someone else's data center. Hermes, Perplexity and OpenClaw are the first three officially supported. The reviewer found Hermes mostly two clicks, while OpenClaw complained about a local gateway until he uninstalled and reinstalled it, so the count is closer to two clicks plus one existential reinstall.

The reviewer also noted that large local models respond more slowly than cloud ones, so he expects to use them for overnight or background work. A laptop that thinks while you sleep is a fine product, though it is not quite the instant assistant the marketing implies.

Memory is the other selling point. Microsoft's Surface Laptop Ultra can ship with up to 128GB of unified memory, meaning the CPU and GPU share one pool, which lets huge models fit. Microsoft says it holds back a little so the system stays responsive. Machines with 24GB or 32GB get a slider in Nvidia's Windows app to shift memory toward the GPU, a tool for deciding which of your programs deserves to be starved.

Gaming is where Arm laptops have historically stalled, partly because anti-cheat software refused to cooperate. Fortnite, Marvel Rivals, Arc Raiders, Counter-Strike 2 and Dota 2 are supported out of the box. Call of Duty's anti-cheat arrives at some point in 2027, Battlefield's in early 2027, and PUBG in the first half of 2027. Riot has committed to League of Legends and Valorant with no date. The reviewer reached a stable 60fps in most games at medium settings, 1440p and DLSS performance, which is below a dedicated gaming laptop. Microsoft and Nvidia say these are not gaming machines, then list the games.

Not everything shipped. Copilot Plus PC features such as Recall are absent at launch, and Microsoft's Adrienne Brewbaker said they are expected to reach Windows Insiders later this year. It is not clear why they are delayed. Recall's absence may disappoint some buyers and relieve others.

Meanwhile, Microsoft says months of fixes have made Windows 11 up to 20 percent more responsive. Navjot Virk, a Microsoft corporate vice president, said Windows can now keep up to 2GB more active data in memory instead of moving it to slower storage. On PCs with 8GB or less, Widgets load only when opened, freeing more than 200MB. Microsoft also let the taskbar move to the sides or top of the screen, a feature the world has requested since roughly the first taskbar.

Other fixes include a less disruptive Windows Update, faster Windows Hello sign-in, and an AirPods pairing experience up to 15 seconds faster. A faster Search is available to Insiders and is due to roll out more broadly later this year. The overall message is that Windows is getting leaner on cheap machines and ambitious on expensive ones, and the 8GB owner now gets some of the benefit.
