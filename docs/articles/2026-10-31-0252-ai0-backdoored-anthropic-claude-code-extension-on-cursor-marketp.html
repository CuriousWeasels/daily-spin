Fake Claude Extension Spends Half a Day in Cursor Marketplace, Politely Asks for Everything

A tampered version of Anthropic's Claude extension reached up to 5,000 Cursor users before the marketplace was pulled offline, and the two sources disagree on who was responsible for what.

The wire said: Anthropic VS code extension on Cursor backdoored for nearly 12 hours · Ars Technica AI

By The Daily Spin Desk · AIOct 31, 2026 02:52 UTC · 2 min read

Catch up

Cursor is a maker of AI-assisted coding tools whose marketplace hosts VS Code extensions, including one for Anthropic's Claude. A malicious version of that extension was published there and later removed.

Why it matters

Developers install extensions on machines holding source code, credentials and company access, so one poisoned update can reach far more than one laptop. Auto-update, a convenience, is also the delivery route.

A malicious version of the Claude Code extension was available in Cursor's extension marketplace for roughly eleven to twelve hours, affecting at most 5,000 users, according to Cursor. Ars Technica reported the figure Friday, and The Decoder reported a similar window. The reports differ slightly on timing: Ars says nearly 12 hours, The Decoder says about eleven, and says the tampered version appeared Thursday.

The sources also differ on how the package got there. Ars Technica reported that researcher Kevin Beaumont and Luke Roberts, CTO and co-founder of security firm Phorian, said version 2.1.313 was distributed through Anthropic's official account on Cursor. The Decoder, citing Cursor, said Anthropic had no involvement in developing it. Both can be true: the account can be official while the author is not. Neither Cursor nor Anthropic has explained how attackers gained control of the account, according to Ars.

Roberts described it to Ars as a supply-chain compromise. Translation: instead of breaking into thousands of computers one at a time, the attacker broke into the one place everyone trusts and let the software update do the delivery. Extensions in Cursor auto-update by default, though users can change that setting. The malicious version replaced 2.1.312, and Anthropic pushed a clean 2.1.314 several hours later, per Beaumont.

As for what the code tried to do, Cursor said it attempted to install a persistent SSH backdoor by adding an attacker-controlled SSH key, enabling the local SSH service and opening a reverse SSH tunnel. Translation: it tried to leave a key under the mat and then call the burglar to say the door was open. It was written to work on Windows, macOS and Linux, which is inclusive of it. The Decoder added that it tried to collect hostname, username, operating system and public IP address.

The damage may be limited. Cursor told The Decoder the remote access piece likely would not have worked on most machines because it requires admin privileges. Ars noted, however, that because extensions run with the permissions of the development environment, a backdoored version would likely reach local files, source code and developer tooling. Both statements can be reassuring or alarming depending on how your laptop is set up.

Once the problem was found, Cursor pulled the extension and took the entire marketplace offline. It reinstated the marketplace after working with providers to neutralize the malware and confirming no further risk, and says no other extensions were affected. Ars reported that Anthropic had not yet issued a public notice to customers.

The next thing to watch is the explanation. Until someone says how the account was taken over, the official channel remains the one thing users were told to trust and cannot yet verify.
